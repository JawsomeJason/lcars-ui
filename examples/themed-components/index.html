LCARS Theme Inheritance Example

About This Example

This demonstrates theme inheritance via the data-theme attribute.

All panels inside a container with data-theme="2357" automatically inherit the theme colors.

User Story 2: Apply color theme ✓

Section 1: Explicitly Themed Container

This panel inherits the 2357 theme from its parent container.

Notice the golden-tanoi background and neon-carrot border.

This info variant panel also inherits the 2357 theme.

It uses anakiwa background and mariner border.

Alert variant panel with 2357 theme colors.

Uses pale-canary background from the 2357 palette.

Section 2: No Explicit Theme (Inherits from :root)

This panel has no explicit data-theme set on itself or container.

It falls back to the default 2357 theme from :root.

Info panel without explicit theme.

Still uses 2357 colors as the default fallback.

Section 3: Nested Theme Inheritance

This panel's container has data-theme="2357".

This nested panel is inside another panel's slot.

It still inherits the 2357 theme from the closest themed ancestor.

Theme Inheritance Test Results

✓ Panels inherit theme from container with data-theme="2357"

✓ Panels without explicit theme fall back to :root default (2357)

✓ Nested components inherit from closest themed ancestor
